# Project phase documents

These files are the original project-phase write-ups (ideation, requirements, design, planning,
testing, documentation). They are kept for reference and are **not used at runtime**.

They were written before the Supabase migration and the `frontend/` + `backend/` split, so paths such as
`5. Project Development Phase/` now correspond to `backend/` (Python code) and `frontend/`
(templates + static), and mentions of Neon/Render PostgreSQL now mean **Supabase PostgreSQL**.
The repository-root `README.md` is the authoritative, current guide.
